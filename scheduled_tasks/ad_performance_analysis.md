# 일일 광고 성과 분석 — PLANDOG

마케팅 에이전트의 광고 분석 담당입니다. 전날의 광고 캠페인 성과를 분석하고 실행 가능한 리포트를 작성합니다.

## 제품 컨텍스트
- 제품: 플랜도그(PLANDOG) — 대화 기반 화면설계서 생성 AI 도구
- 웹사이트: https://plandog.net/
- 타겟: PM/기획자, 1인 개발·창업팀, SI/에이전시, 개발팀
- 핵심 전환: 웹사이트 방문 → 무료 체험 시작 (웰컴 크레딧)

## 단계

1. **광고 데이터 수집** — 각 플랫폼의 캠페인 메트릭을 가져옵니다:
   ```bash
   curl -s http://localhost:8000/api/ads/campaigns
   curl -s http://localhost:8000/api/ads/campaigns/{id}/metrics?days=1
   ```

2. **현재 전략 확인** — `config/strategy.yaml`에서 성과 임계값을 확인합니다.

3. **성과 분석**:
   - 캠페인별 CTR(클릭률) 분석 — 2% 이상이면 양호, 0.5% 미만이면 소재/타겟 수정 필요
   - CPC(클릭당 비용) 추이 — PM/UX 키워드는 경쟁이 심하므로 CPC 모니터링 중요
   - 전환율 변화 — plandog.net 랜딩 → 무료 체험 전환율 추적
   - 소재별 성과 비교 — "5분 만에 기획서" vs "AI 와이어프레임" 등 메시지별 반응 차이

4. **리포트 생성** — `reports/ad_daily_YYYY-MM-DD.md`에 작성:
   - 핵심 요약 (총 지출, 총 클릭, 평균 CTR, 전환 수)
   - 플랫폼별 상세 현황
   - 성과 상위/하위 캠페인 분석
   - 소재/타겟팅 개선 제안
   - 플랜도그 타겟 키워드 추천 (PM도구, 기획서자동화, AI와이어프레임 등)

5. **이상 징후 기록** — CTR이 급락하거나 CPC가 급등한 캠페인을 플래그합니다.

## 중요 사항
- 광고 데이터가 아직 없는 초기 단계에서는 "아직 캠페인 데이터 없음 — 캠페인 생성을 권장합니다"로 리포트 작성
- 플랜도그의 핵심 타겟(PM, 기획자)에게 도달하는 키워드/타겟팅 효과를 중점 분석
- 경쟁사(Figma, Whimsical, Notion AI, Miro) 대비 차별화 메시지 효과 분석
