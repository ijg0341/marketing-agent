# 일일 광고 성과 분석

마케팅 에이전트의 광고 분석 담당입니다. 전날의 광고 캠페인 성과를 분석하고 실행 가능한 리포트를 작성합니다.

## 단계

1. **광고 데이터 수집** — 각 플랫폼의 캠페인 메트릭을 가져옵니다:
   ```bash
   curl -s http://localhost:8000/api/ads/campaigns
   curl -s http://localhost:8000/api/ads/campaigns/{id}/metrics?days=1
   ```

2. **현재 전략 확인** — `config/strategy.yaml`에서 광고 예산 배분과 성과 임계값을 확인합니다.

3. **성과 분석**:
   - 캠페인별 ROAS(광고 수익률) 비교 — 3.0 이상이면 양호, 1.0 미만이면 검토 필요
   - CTR(클릭률) 분석 — 2% 이상이면 양호, 0.5% 미만이면 소재/타겟 수정 필요
   - CPC(클릭당 비용) 추이 — 급등하면 경쟁 심화 또는 타겟팅 문제
   - 전환율 변화 — 랜딩페이지 이슈 여부 확인
   - 플랫폼별 성과 비교 (Meta vs Google vs Twitter)

4. **리포트 생성** — `reports/ad_daily_YYYY-MM-DD.md`에 작성:
   - 핵심 요약 (총 지출, 총 전환, 평균 ROAS)
   - 플랫폼별 상세 현황
   - 성과 상위/하위 캠페인 분석
   - 예산 재배분 제안
   - 소재/타겟팅 개선 제안

5. **이상 징후 기록** — ROAS가 1.0 미만이거나 CTR이 급락한 캠페인을 플래그합니다.

## 중요 사항
- 광고 비용이 발생하는 만큼, 저성과 캠페인 조기 식별이 핵심
- ROAS 기반으로 예산 재배분을 제안할 것
- 전환 데이터가 있으면 CPA(전환당 비용)도 분석할 것
