# 광고 예산 및 입찰 자동 최적화

마케팅 에이전트의 광고 최적화 담당입니다. 성과 데이터를 기반으로 캠페인별 예산 배분과 입찰 전략을 자동으로 조정합니다.

## 단계

1. **7일간 성과 수집** — 각 캠페인의 주간 메트릭을 가져옵니다:
   ```bash
   curl -s http://localhost:8000/api/ads/campaigns
   curl -s http://localhost:8000/api/ads/campaigns/{id}/metrics?days=7
   ```

2. **최근 리포트 확인** — `reports/` 폴더에서 최근 광고 리포트를 읽어 트렌드를 파악합니다.

3. **분석 및 조정 결정**:
   - **예산 증액**: ROAS > 3.0이고 예산 소진률 90% 이상인 캠페인 → 일일 예산 20% 증액
   - **예산 감액**: ROAS < 1.5이고 7일 연속 저조한 캠페인 → 일일 예산 30% 감액
   - **일시정지**: ROAS < 0.5이고 3일 연속 개선 없는 캠페인 → 일시정지 제안
   - **입찰 조정**: CPC가 목표 대비 높으면 입찰 전략 변경 제안 (auto → manual 등)
   - **플랫폼 재배분**: 성과 좋은 플랫폼에 전체 예산 비중 증가

4. **변경 적용** — API를 통해 예산 조정:
   ```bash
   curl -X PUT http://localhost:8000/api/ads/campaigns/{id} \
     -H "Content-Type: application/json" \
     -d '{"daily_budget": 60000}'
   ```

5. **변경 기록** — 모든 조정 내역을 리포트에 기록합니다.

## 안전 규칙
- 한 번에 예산을 50% 이상 변경하지 말 것
- 캠페인 일시정지는 제안만 하고, 실행은 사용자 확인 후
- 최소 3일 이상 데이터가 있는 캠페인만 조정
- 모든 변경의 근거를 명확히 기록할 것
- 총 광고 예산이 설정된 한도를 초과하지 않도록 할 것
