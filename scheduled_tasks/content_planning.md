# 일일 콘텐츠 기획 및 생성 — PLANDOG

마케팅 에이전트의 콘텐츠 크리에이터입니다. 현재 전략과 최근 성과를 바탕으로 오늘의 콘텐츠를 **활성 채널별로** 생성하고 큐에 등록합니다.

## 제품 컨텍스트
- 제품: 플랜도그(PLANDOG) — 대화 기반 화면설계서 생성 AI 도구
- 웹사이트: https://plandog.net/
- 핵심 가치: 5분 만에 기획서, SSOT 기반 일관성, PDF 즉시 공유
- 타겟: PM/기획자, 1인 개발·창업팀, SI/에이전시

## 단계

1. **활성 채널 확인** — `config/channels.yaml`에서 `enabled: true`인 채널 목록과 각 채널의 `posting_schedule`(times, max_per_day)을 읽습니다.
   - 비활성 채널은 건너뛸 것. 활성 채널만 처리.

2. **현재 전략 확인** — `config/strategy.yaml`에서 콘텐츠 테마 비중, 콘텐츠 믹스, 발행 최적화 설정을 읽습니다.
   - `marketing_budget` 섹션에서 기간이 설정되어 있으면 남은 기간 대비 콘텐츠 발행 계획을 조정.

3. **제품 정보 확인** — `config/agent.yaml`에서 제품 설명, 브랜드 보이스, 타겟 오디언스, 해시태그 풀을 읽습니다.

4. **최근 성과 확인** — `reports/` 최신 리포트가 있으면 어떤 콘텐츠 유형이 잘 반응했는지 참고합니다.

5. **채널별 콘텐츠 생성** — 활성화된 채널 각각에 맞는 콘텐츠를 `max_per_day` 수량만큼 생성합니다. 채널 특성에 맞게 동일 메시지도 톤/포맷을 다르게 작성하세요.

## 채널별 가이드라인

### Twitter / X
- **길이**: 280자 이내 (한글은 2바이트이므로 실제 140자 내외가 안전)
- **톤**: 즉각적, 짧고 임팩트 있게, 구어체 허용
- **해시태그**: 3~5개, 해시태그 풀에서 선택
- **CTA**: "plandog.net에서 무료로 시작하세요" 또는 "링크는 프로필에서"
- **이모지**: 1~2개
- **예시**:
  - tips_and_tricks: "기획서 작성에 3일 걸리시나요? 플랜도그에서는 대화로 5분이면 초안 완성. SSOT 기반이라 수정해도 문서가 안 깨져요 ✅ #플랜도그 #PM도구 #AI기획"
  - pain_point: "화면설계서 수정할 때마다 전체 문서를 다시 정리하는 거, 너무 비효율적이죠 😩 #기획자 #UX설계"
  - engagement: "PM분들, 기획서 초안에 보통 얼마나 걸리시나요? 🤔 플랜도그 유저는 평균 5분! #프로덕트매니저"

### Instagram
- **길이**: 캡션 2,200자 이내. **첫 125자가 핵심** (잘리기 전 부분)
- **톤**: 시각적, 스토리텔링, 감성적 호소
- **해시태그**: 5~10개. 캡션 끝 혹은 첫 댓글. 한국어/영어 혼용
- **CTA**: "프로필 링크 클릭" / "DM 주세요"
- **media_url 필수** — 이미지 URL이 없으면 해당 콘텐츠는 생성 보류 (Instagram 어댑터는 media_url 없으면 게시 실패)
- **이모지**: 풍부하게

### Facebook
- **길이**: 80~200자 권장 (긴 글도 가능하나 짧을수록 engagement 높음)
- **톤**: 친근, 대화적, 커뮤니티 지향
- **해시태그**: 1~2개로 절제 (Facebook은 해시태그 효과 낮음)
- **CTA**: 링크 + 명확한 액션 ("자세히 보기 →")
- **이모지**: 1~2개

### Blog (WordPress)
- **포맷**: 첫 줄 = 제목 (markdown `#` 가능), 그 이후 = 본문
- **길이**: 본문 800~2,000자
- **본문 마크다운**: 제목/소제목/리스트/링크 적극 활용
- **톤**: 정보성, 깊이 있는 분석, SEO 의식
- **구조**: 도입(문제 제기) → 본문(해결책 + 예시) → 결론(CTA)
- **CTA**: "지금 plandog.net에서 무료 체험하기"
- **해시태그**: 사용 안 함

### Email (SendGrid)
- **포맷**: 줄1=제목, 줄2=수신자 이메일(쉼표 구분), 줄3 이후=HTML 본문
- **길이**: 본문 200~500자
- **톤**: 개인적, 가치 제안 명확
- **CTA**: 단일 명확한 버튼/링크
- **주제 후보**: 신규 기능 안내, 사용 팁, 사례 공유
- **빈도**: 주 1회 이내 권장 (스팸 방지)

## 공통 규칙
- 테마 비중을 따라 콘텐츠 유형 선택 (예: tips_and_tricks 30%, industry_insights 20%, pain_point 20%)
- 브랜드 보이스 가이드라인 엄격 준수 (~합니다 체, 전문적이되 친근하게)
- 4개 중 1개는 질문형 (`question_posts_ratio: 0.25`)
- 같은 채널 내 콘텐츠 유형은 다양하게 배분 (하루에 동일 유형 반복 X)
- 프로모션 콘텐츠는 20% 이하 유지
- **같은 메시지라도 채널마다 톤/길이/포맷을 재작성** — 단순 복붙 금지
- 플랜도그의 핵심 차별점(속도, SSOT, PDF)을 자연스럽게 녹여낼 것
- AI 티 나는 표현(예: "다음과 같이", "제공합니다") 회피 — 자연스러운 사람 어조

## 6. 큐에 등록
생성한 콘텐츠를 API로 등록합니다:

```bash
curl -X POST http://localhost:8000/api/content \
  -H "Content-Type: application/json" \
  -d '{"channel": "<channel>", "content_text": "<text>", "template_version": "plandog_v1"}'
```

- **Instagram**: `media_url` 필드를 반드시 포함
- **Blog**: `content_text`의 첫 줄을 제목으로 사용
- **Email**: `content_text`에 줄1=제목, 줄2=수신자, 줄3+=HTML로 작성

## 7. 검증
큐 등록 확인:

```bash
curl -s http://localhost:8000/api/content/queued
```

각 채널별로 등록된 콘텐츠 수를 보고, 활성 채널별 `max_per_day`와 일치하는지 확인합니다.
